# 書き方の早見表

エディターでは ツールバーの「書き方」（⌘⇧K）で、見本を見ながらそのまま入れられます。
この表は `marp/cheatsheet.mjs` から `node marp/scripts/cheatsheet-md.mjs` で作っています（直接は直さない）。

## ページの基本

### 1ページの形

使いどころ：すべてのページ

```markdown
# タイトル

最初の段落がリード文になります。読む理由と結論を2行までで。

ここから下が本文（図・部品・箇条書き）です。
```

- `---`（前後に空行）でページを区切る
- リードを出したくないページは `<!-- _class: no-lead -->`

### フロントマター（資料全体の設定）

使いどころ：ファイルの先頭に1回

```markdown
---
marp: true
theme: paper
paginate: true
title: "資料のタイトル"
chapters: [基礎, 仕組み, 使ってみる]
photos: [私=figs/me.png]
style: |
  section { --accent: #574789; --font-scale: 1.06; }
---
```

- `--accent` はアクセント色、`--font-scale` は文字の大きさ（全体）
- `chapters` と `photos` は下の「章のパンくず」「顔写真」を参照

### 章のパンくず

使いどころ：章のあるデッキ

```markdown
<!-- chapter: 仕組み -->
```

- 章の最初のページに1回書くと、以降のページに続く
- 章の一覧はフロントマターの `chapters`
- このページだけフッターを消す: `<!-- _footer: "" -->`

### 発表者ノート

使いどころ：話すこと・出典

```markdown
<!--
ここに話すことや出典を書きます。スライドには出ません。
-->
```

- ディレクティブ（`_class:` など）でないコメントがノートになる

## ページの種類

### 表紙

使いどころ：1ページ目

```markdown
<!-- _class: cover cover-talk -->

# 読書メモから<br>次の一冊を選ぶ

<p class="kicker">読書メモ <span>勉強会</span></p>

<p class="sub">読み終えた本に一行だけ書き添える</p>

<p class="who"><b>Your Name</b></p>

![](figs/cover-art.svg)
```

- 右の560×720の面（色・点・円弧）はテーマが描く。挿絵は透明な地に題材の主役だけを描いて置く。
- 肩の `kicker` に資料名、`span` に日付・イベント名・持ち時間を書く。罫の右に小さく出る。
- 右の面を濃くするなら両端を `stage` にする（`layout: stage` の資料は自動）。表紙と裏表紙は同じ指定にする。

### 章扉

使いどころ：章の始まり

```markdown
<!-- _class: divider -->

# 章の名前

この章で話すことを1行で。
```

### 裏表紙

使いどころ：最後のページ

```markdown
<!-- _class: closing back-cover -->

# ありがとうございました

<p class="kicker">読書メモ <span>勉強会</span></p>

<p class="who"><b>Your Name</b></p>

![](figs/cover-art.svg)
```

- 表紙と同じ肩・署名・挿絵を置く。署名の後にMarkdownリンクの段落を書くと、題名の下に連絡先として出る。

### 本文を縦中央に

使いどころ：部品が小さく、上に寄って見えるとき

```markdown
<!-- _class: centered -->
```

### 主張のページ

使いどころ：一言で言い切るとき

```markdown
<!-- _class: statement -->

# 見出し

大きな文字で言い切る一文。
```

### 図を全面に

使いどころ：図だけで見せるページ

```markdown
<!-- _class: full -->

# タイトル

![](figs/x.svg)
```

- フッターが消え、図が本文の領域いっぱいに広がる

## 図・コード・表

### 図（SVG）

使いどころ：リード＋図の基本のページ

```markdown
![h:380](figs/x.svg)
```

- `h:380` は高さ（328〜410px が目安）。細部を読ませる図は縮めない
- エディターでは図をダブルクリックで直接編集
- 図は `figs/src/make_figs.py` で作って `slides figs` で作り直す

### コード（ウィンドウ風）

使いどころ：設定やコードを見せる

```markdown
```python ウィンドウの見出し
def handler(event, context):
    return {"ok": True}
```
フェンスの直後の段落がキャプションになります
```

- 言語なしは ` ```text 見出し `
- Mermaid は ` ```mermaid `

### 表

使いどころ：観点ごとの比較・一覧

```markdown
| 項目 | 説明 |
| --- | --- |
| 1つ目 | **強調**もできる |
| 2つ目 | セルの中の改行は <br> |
```

- 大きさは `::: scale 1.2` で包む
- 1列目は太字・薄い地になる

## 会話・語り

### 掛け合い

使いどころ：疑問と答えで話を進める

```markdown
::: dialogue 0.95
- 私: ここに疑問を書きます。
  2行目も書けます。
- Agent君: ここに答えを書きます。
:::
```

- 名前に agent / AI / bot を含むと右・ロボットのアイコン
- 明示: `- [ai] 名前:` `- [person right] 名前:`
- 顔写真: `- [photo=figs/me.png] 私:`（全体はフロントマターの `photos`）

### 語りかけ

使いどころ：自分の言葉で1つ伝える

```markdown
::: speech 私
ここに**語りかけ**を書きます。
:::
```

- 顔写真: `::: speech 私 photo=figs/me.png`
- 縦中央と合わせると収まりがよい: `<!-- _class: centered lead-1 -->`

### 帯

使いどころ：結論をひと言で強調

```markdown
::: band
ここに**伝えたいこと**を書きます。
:::
```

### 話者の顔写真

使いどころ：「私」を写真にしたい

```markdown
photos: [私=figs/me.png]
```

- フロントマターに書く（資料全体の既定）
- 1か所だけ変える: `- [photo=figs/other.png] 私:`

### 引用（人の言葉）

使いどころ：発言を引用する

```markdown
::: quote
小さく始めて、成功事例が増えてから共通化を進めましょう。

— 出典の名前『資料名』
:::
```

- 「— 」で始まる段落が出典になる

### 語り（文章）

使いどころ：おわりに・まとめの文章

```markdown
::: prose 1.15
ここに締めくくりの文章を書きます。**伝えたいこと**は太字に。

段落を分けて書けます。
:::
```

## 構造の部品

### 対象と目的

使いどころ：冒頭で誰に向けた資料かを示す

```markdown
::: purpose 1.12
- 対象
  - この技術を知り、使ってみたい方
- **目的**
  - 全体像と使い分けを理解する
:::
```

- `**目的**` のように太字の行が強調される

### アジェンダ

使いどころ：章の並び

```markdown
::: agenda
1. 1つ目の章
   2行目が説明になります
2. 2つ目の章
3. 3つ目の章
:::
```

### 場面図

使いどころ：誰が誰に何を頼むか

```markdown
::: scene 1.28
- [user] 利用者: ここに依頼を書きます
  → 依頼
- [agent!] Agent君 {実行基盤}: 次に何をするか考える
  → 呼び出し
- [server] 外部サービス
:::
```

- アイコン: user / agent / llm / server / db / doc / browser / tool / search / mail / calendar / chat / cloud / pc
- `[agent!]` で強調、`{外枠 / 内枠}` で枠、`{~LLM}` で破線の枠
- `### キャプション | 結論` でグループを分ける

### 流れ

使いどころ：処理の順番

```markdown
::: flow 1.28
- 判断: 必要な情報とツールを選ぶ
- **呼び出し**: 接続先へ要求する
- 観測: 結果やエラーを読む
:::
```

- 縦に並べる: `::: flow vertical`
- `**タイトル**` の段が強調される

### 比較

使いどころ：2〜3案の違い

```markdown
::: compare 1.28
- 案A
  - 良いところ
  - 気をつけるところ
- 案B
  - 良いところ
  - ※ 向いている場面
:::
```

- 「※」で始まる項目は列の補足

### 見出しつき箇条書き

使いどころ：観点ごとに短く並べる

```markdown
::: bullets 1.18 rule
### 観点1
- 短く1行で
### 観点2
- 短く1行で
:::
```

- `rule` で上に罫線

### 補足の囲み

使いどころ：表やコードの下に1〜2行

```markdown
> [!設定] 見出しつきの補足を1〜2行で書きます。
```

- 見出しなしは `> 補足`

### 自己紹介

使いどころ：登壇者の紹介

```markdown
::: profile 1.28
![](figs/me.png)
写真の説明（任意）
- 名前: 発表者名
- 関心のある分野: 可視化
:::
```

### リンク

使いどころ：参考資料

```markdown
::: links
- [ドキュメントの名前](https://example.com/): 何の根拠か
- [ブログの名前](https://example.com/): 何の根拠か
:::
```

## 大きさ・調整

### 部品の倍率

使いどころ：部品を大きく・小さく

```markdown
::: dialogue 0.9      ← 部品名のあとの数字が倍率

::: scale 1.2         ← 表・コード・箇条書きなどを包む
| 項目 | 説明 |
| --- | --- |
| 1つ目 | 説明 |
:::
```

- 見切れたら、倍率を下げる前に文言・改行・図の余白を見直す
- エディターの右側のスライダーでも変えられる

### リードの大きさ

使いどころ：リードが長い・短い

```markdown
<!-- _class: lead-s -->
```

- `lead-1` 1.0 / `lead-11` 1.1 / `lead-s` 1.12 / `lead-m` 1.16 / `lead-l` 1.26（既定 1.2）
- クラスは空白で並べる: `<!-- _class: centered lead-1 -->`

### このページだけの調整

使いどころ：1枚だけ色や余白を変える

```markdown
<style scoped>section { --lead-scale: 1.1; --accent: #825539; }</style>
```

- タイトルより前に書く
- 全体の設定はフロントマターの `style`
