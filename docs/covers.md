# 表紙と裏表紙の作り方

表紙には `cover cover-talk`、裏表紙には `closing back-cover` を指定します。どちらも左に題名と発表者名を置き、右に同じ挿絵を使います。Petrol と Paper は右側が淡い色に、`layout: stage` を指定した資料では濃い色になります。

| 原稿の要素 | 表紙と裏表紙への入れ方 |
| --- | --- |
| `kicker` | 左上に資料名を書きます。`span` に日付やイベント名を入れると、その手前に細い罫が入ります。 |
| `#` の題名 | 左の文字幅は約620pxです。全角11字前後を目安に `<br>` を入れ、2〜3行に収めます。裏表紙ではこの位置に「ありがとうございました」と書きます。 |
| `sub` | 表紙の題名の下に副題を置きます。裏表紙には連絡先のリンクを置けます。 |
| `who` | 左下に発表者名を太字で書き、その下にローマ字の読みを添えます。 |
| 挿絵 | 右の560×720pxに、題材の仕組みが伝わる絵を一つ置きます。背景の点と円弧はテーマが描くので、挿絵の地は透明にします。 |

エディターの「挿入」から裏表紙を追加すると、1ページ目の肩・署名・挿絵が引き継がれます。表裏を並べて、改行と署名の位置を確認してください。
