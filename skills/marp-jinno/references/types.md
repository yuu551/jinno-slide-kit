# 型と見本のページ

作例は `examples/gallery/<名前>/slides.md`（原稿）・`figs/`（図とその作成元）・`<名前>.pdf`（書き出し）。ページ番号はPDFのページ。原稿は見出しで検索すると、リード・図の高さ・発表者ノートを一緒に読める。PDFはReadツールでページを指定して開ける（例 `examples/gallery/cognito-cimd/cognito-cimd.pdf` の pages `28`）。

新しいページを書く前に、下の表で同じ役割の見本を1〜2枚開く。見るのは文字の量・図の大きさ・役者と公式アイコンの置き方・吹き出しの位置。題材・値・枠の構造はそのまま写さない。

## 同じ役割の見本ページ

| ページの役割 | 見本（作例とページ） | 図の作り方 |
|---|---|---|

| 誰が何をしたい場面か | CIMD p.6（scenario.svg）、RAG p.8、Jev p.4 | 人の線画＋依頼の吹き出し＋使う道具＋サービスの公式アイコン。境界（利用者のPCなど）を枠で示す |

表のページは作例全体で188枚中3枚。表にしてよいのは最後の行のような値の一覧だけで、流れ・前後比較・構成・条件の分岐は図にする（[図の選び方](figures.md)）。

## 型ごとの並び

雛形は `marp/templates/<型>/slides.md`。`slides templates` で一覧が出る。どの型でも雛形の文と図はすべて題材に合わせて書き換える。

| 型 | 使う場面 | 並び |
|---|---|---|
| update | 1つのアップデートの解説 | [アップデート紹介の型](update.md) |
| talk | 登壇・勉強会 | 表紙 → 問いかけ → 場面 → 章ごとに（章扉 → 会話 → 図のページ → 帯でまとめ）→ 締め → おわりに → 裏表紙 |
| webinar | デモを含む長めの説明 | talk と同じ並びに、デモの結果（画面・出力）を足す。全体図を最初に見せ、章ごとに同じ図で今の位置を示す（RAG p.9・28・40・53・63） |
| lightning | 5分の発表 | 表紙 → 場面 → 一番見せたい図1〜2枚 → 結果 → 裏表紙 |
| release | アプリの変更前後 | 表紙 → 何が変わったか → 前後の画面 → 使い方 → 裏表紙 |

## 登壇の流れ

表紙 → 聴き手が知っている場面 → 疑問 → しくみ → 同じ例の実行結果 → 次の一歩。章が変わる所に章扉か帯を置く。「ここで紹介するのは…」をくり返すより、見出しを「どの条件で処理が止まる？」、リードを「入力を受け取ったProxyが判定し、違反ならモデルに送る前に止めます」のように書く。

長い資料（30枚以上）では、導入で全体図を見せ、各章の頭で同じ図の該当箇所だけを強調する（RAG p.9 → p.28・40・53・63）。全体図・章の名前・パンくず（フロントマターの `chapters`）の名前を合わせる。

## Markdownで書く部品

- 表紙は `<!-- _class: cover cover-talk -->`、裏表紙は `<!-- _class: closing back-cover -->`。章扉は `divider`、強い一言は `::: band`、人物の疑問と応答は `::: dialogue`、一人の発言は `::: speech`、対象と目的は `::: purpose`。表はMarkdown、設定は言語名と見出し付きのコードフェンス。各ページのリードは見出しの直後に通常の段落で書く。
- 図は `![h:380](figs/x.svg)` のように高さを決める。N は図の高さ（`Fig` の第2引数）と同じにする。作例の実績は328〜420px。細部を読ませる図を縮めて収めない。
- 横長の表やコードを主役にするときはフロントマターに `layout: classic`、大きな色面の章扉には `layout: stage` を使える。どちらも `theme: petrol` と `theme: paper` に対応する。
- 部品の書式と倍率はキットの `docs/cheatsheet.md`。部品と同じ見た目をSVGに焼き込まない。
- 会話（`::: dialogue`）は発話2〜3つまで。リードが2行あると発話3つでも収まらないので、会話のページのリードは1行にするか省く。それ以上話したいなら会話を分けるか図にする。
- コードは倍率1.0で9行前後まで。それより長いときは要らない行を省くか `::: scale 0.85` で包み、実寸で読めるか確かめる。
- 表の1列目が折り返すときは、フロントマターの `style:` に `table td:first-child, table th:first-child { white-space: nowrap; }` を足す（CIMD の原稿の先頭にある）。
- `::: band` を表やコードの直後に置かない。残りの高さいっぱいに伸びて見切れる。帯は帯だけのページか、短いリードのあとに置く。
